A full-stack social platform with user auth, a vector-based face-matching service, and an LLM assistant that uses embeddings and retrieval. Feed ranking and friend recommendations run on Spark with PageRank-style algorithms.

**Stack:** React, Node, AWS (DynamoDB, S3, EMR), Spark, Docker.
