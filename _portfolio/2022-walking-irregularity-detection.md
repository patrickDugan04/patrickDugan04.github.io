A team research project from the New Jersey Governor's School in the Sciences on using machine learning to detect walking irregularities that can signal movement disorders. I wrote most of the data processing and ML code. The team's report is [here](https://drew.edu/wp-content/uploads/sites/28/2022/11/T9.pdf); it was not formally published.

My fork of the code is on [GitHub](https://github.com/patrickDugan04/walking-irregularity-detection).
